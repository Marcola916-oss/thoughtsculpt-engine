█  SEÇÃO 4 — ARQUITETURA DE SEGURANÇA


▶ 4.1 Princípios de Segurança
RLS ativa em TODAS as tabelas (confirmado nas criações da Seção 3)
STRIPE_SECRET_KEY e SUPABASE_SERVICE_ROLE_KEY: APENAS em Edge Functions. Nunca no frontend.
NEXT_PUBLIC_* variáveis: podem ir no frontend — são keys públicas projetadas para isso
Validação de webhooks Stripe: verificar assinatura com stripe.webhooks.constructEvent() usando STRIPE_WEBHOOK_SECRET antes de processar qualquer evento
Rate limiting nas Edge Functions: máximo 10 chamadas por IP por minuto para endpoints de geração de IA
Sanitização de inputs: limpar todo texto livre antes de enviar para a OpenAI API

▶ 4.2 Validação do Webhook Stripe — Código de Referência
// Supabase Edge Function: stripe-webhook.ts
import Stripe from 'https://esm.sh/stripe@14';

const stripe = new Stripe(Deno.env.get('STRIPE_SECRET_KEY')!);
const webhookSecret = Deno.env.get('STRIPE_WEBHOOK_SECRET')!;

Deno.serve(async (req) => {
  const signature = req.headers.get('stripe-signature')!;
  const body = await req.text();

  let event: Stripe.Event;
  try {
    event = stripe.webhooks.constructEvent(body, signature, webhookSecret);
  } catch (err) {
    // Assinatura inválida — rejeitar
    return new Response('Webhook signature invalid', { status: 400 });
  }

  switch (event.type) {
    case 'customer.subscription.created': await handleSubscriptionCreated(event); break;
    case 'invoice.payment_succeeded':     await handlePaymentSucceeded(event); break;
    case 'invoice.payment_failed':        await handlePaymentFailed(event); break;
    case 'customer.subscription.deleted': await handleSubscriptionDeleted(event); break;
    case 'charge.refunded':               await handleRefund(event); break;
  }
  return new Response(JSON.stringify({ received: true }), { status: 200 });
});

▶ 4.3 Proteção contra Abuso de IA — Middleware de Rate Limiting
// Antes de qualquer chamada OpenAI, verificar daily_limits:
async function checkAndIncrementLimit(userId, limitType, planType) {
  const today = new Date().toISOString().split('T')[0];
  const maxLimits = {
    '1y': { generations: 10, calendars: 15, pdfs: 15 },
    '6m': { generations: 999, calendars: 999, pdfs: 999 },
    '30d': { generations: 999, calendars: 1, pdfs: 5 }
  };
  const limits = maxLimits[planType] || maxLimits['30d'];
  const fieldMap = { generation: 'generations_count', calendar: 'calendars_count', pdf: 'pdfs_count' };
  const field = fieldMap[limitType];

  const { data } = await supabase.from('daily_limits')
    .upsert({ user_id: userId, date: today }, { onConflict: 'user_id,date' })
    .select().single();

  if (data[field] >= limits[limitType + 's']) {
    throw new Error('DAILY_LIMIT_REACHED');
  }
  await supabase.from('daily_limits')
    .update({ [field]: data[field] + 1 })
    .eq('user_id', userId).eq('date', today);
}

▶ 8.2 Guards de Autenticação — Lógica Completa
// Middleware de rota para todas as /dashboard/*:
1. Verificar Supabase session. Se null → redirect /login
2. Buscar users.access_level:
   - 'active'  → acesso normal
   - 'grace'   → exibir banner de aviso (pagamento em retry)
   - 'locked'  → congelar interface + mostrar tela de upgrade
   - 'revoked' → deslogar + redirect /login com mensagem
3. Verificar onboarding_completed:
   - false → redirect /onboarding (intercepta qualquer rota privada)
4. Verificar features_expires_at:
   - Se < NOW() + 3 dias → exibir Tarja Vermelha de aviso
   - Se < NOW() → aplicar pointer-events:none em todo conteúdo

▶ 8.3 Fluxo de Login e Recuperação de Senha
Usuário acessa /login → insere email + senha
Supabase Auth valida. Se válido → redirecionar para /onboarding (se !onboarding_completed) ou /dashboard
Se senha errada → mensagem: 'Email ou senha incorretos. Verifique seus dados.'
Link 'Esqueci minha senha' → /reset-password → campo de email → Supabase envia email com magic link
Email contém link para /reset-password?token=... → usuário define nova senha

▶ 16.1 Lógica de Detecção de Idioma
// Executar em _app.tsx ou no componente raiz ao montar:
async function detectLanguage() {
  // 1. Verificar localStorage (preferência salva)
  const saved = localStorage.getItem('mindreset_lang');
  if (saved) return saved;

  // 2. Verificar navigator.language
  const navLang = navigator.language.toLowerCase();
  const langMap = {
    'pl': 'pl', 'pl-pl': 'pl',
    'ro': 'ro', 'ro-ro': 'ro',
    'ar': 'ar', 'ar-sa': 'ar', 'ar-ae': 'ar', 'ar-qa': 'ar',
    'pt': 'pt', 'pt-br': 'pt', 'pt-pt': 'pt',
  };
  if (langMap[navLang]) return langMap[navLang];

  // 3. Fallback: API de geolocalização
  try {
    const res = await fetch('https://ipapi.co/json/');
    const data = await res.json();
    const countryMap = {
      'PL': 'pl', 'RO': 'ro',
      'SA': 'ar', 'AE': 'ar', 'QA': 'ar', 'KW': 'ar', 'BH': 'ar',
